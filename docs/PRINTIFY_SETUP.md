# Printify Setup Spec — Boogie & The Yo-Yoz

Follow this top to bottom inside Printify. Estimated time: ~45 min for all six products.

---

## 0. One-time setup (10 min)

1. Create a free account at **printify.com**
2. In Printify: **Manage stores → Connect → Shopify** → enter `boogie-the-yo-yoz-merch.myshopify.com` → approve the app install in Shopify
3. Skip Printify Premium for now (upgrade later only if you're doing 10+ orders/day — it cuts base costs ~20%)

## 1. Upload your designs (5 min)

Go to **My Library → Upload** and add both designs:

| File | Name it | Used for |
|---|---|---|
| Text logo ("BOOGIE AND THE YO-YOZ" + character) | `boogie-logo-full` | Fronts and back prints |
| Character only (yo-yo figure, no text) | `boogie-character` | Subtle front-chest prints, hats |

**File requirements:**
- PNG with **transparent background**
- **White or light silver** version of the artwork (it's going on black/dark garments — the dark engraving version will vanish)
- At least **4500 × 5400 px, 300 DPI**. If your current files are smaller, upscale first (Printify warns you if resolution is too low)

## 2. The products

For every product below: **Catalog → search the blank name → pick the print provider → Apply design → set colors/sizes → set retail price → Publish**.

**Print provider rule of thumb:** pick a **US-based provider with the highest ranking score** shown in the provider list (SwiftPOD and Monster Digital are usually top picks for apparel). Use the same provider across products where possible so multi-item orders ship in one package.

## 3. Publishing settings (per product, in the Printify publish screen)

- **Title:** e.g. "Boogie & The Yo-Yoz Vintage Tee"
- **Description:** short + on-brand; mention garment details (Printify pre-fills fabric specs — keep those)
- Publish as **Active**

## 4. After publishing — organize in Shopify admin (10 min)

1. **Shopify Admin → Products** — the Printify items appear automatically
2. Assign each to your existing collections:
   - Tees + long-sleeve → **Shirts**
   - Hoodie + crop → **Hoodies**
   - Hat → **Accessories**
   - Tour long-sleeve → **Limited Edition** too
3. **Retire the placeholder apparel**: set the old seeded shirt/hoodie products to **Draft** (don't delete — keeps order history clean). Keep the tumbler/koozie placeholders until you find a drinkware POD or order those from 24hourwristband in bulk.
4. The app and website pick up all of this automatically — no code changes needed.

## 5. Before going live checklist

- [ ] Order **one sample of the hoodie and vintage tee** for yourself (Printify → order samples, ~40% off). Check print quality before fans do.
- [ ] Set up shipping: easiest is **Shopify Settings → Shipping → flat rate** ($5.99 standard, free over $75) — Printify charges you their shipping per order, your flat rate covers most of it
- [ ] Finish payments setup (PayPal or Shopify Payments) so checkout works
- [ ] Test one end-to-end order with a 100%-off discount code

## Notes

- **Margins:** POD margins run $12–35/item at these prices. Printify charges you (base + shipping) only when an order comes in — zero inventory risk.
- **Drinkware:** Printify does have tumblers/mugs, but engraved-look steel tumblers like your renders are better from a dedicated supplier (what 24hourwristband does) — POD drinkware is printed, not engraved.
- **Gelato:** hold off unless you get international orders — Gelato's strength is EU/global local printing. Adding a second POD later is easy.
